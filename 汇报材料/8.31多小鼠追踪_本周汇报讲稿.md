# 多小鼠追踪：本周学习与任务明确——汇报讲稿

建议时长：5–6 分钟。

## 开场（约 20 秒）

老师好，这周我主要完成的是项目接手、资料学习和任务拆解。目前文件夹里的代码、样例结果和装置设计主要是师兄提供的已有基础，我这周没有新增实验结果。我的阶段性进展，是把现有方案读清楚，并明确后面真正需要解决的问题、技术路线和实施顺序。

目前先不直接进入行为分类，第一步是把多只小鼠长期、稳定地追踪下来，保证每只小鼠的身份 ID 在接触和遮挡前后不会混乱。

---

## 第 1 页：本周学习后，任务被拆成三层（约 60 秒）

师兄提供的 V1 方案已经包含了一个基本流程：先检测和分割小鼠，再用 SAM 2.1 进行 mask 跟踪，最后根据外观和运动信息做身份关联。现有材料中已经有多色鼠的跟踪样例，也有同色鼠处理模块的初步结构。

我这周学习以后，把整个任务拆成了三个层次。

第一层是检测和分割，也就是每一帧里小鼠在哪里，输出 box 或 mask。

第二层是身份关联，也就是当前帧检测到的这只小鼠，究竟对应前面哪一个 ID。

第三层是遮挡恢复。当两只鼠接触、重叠或者短暂消失以后，需要在它们再次分离时恢复正确身份。

所以目前的核心目标不是直接判断小鼠在做什么行为，而是先稳定输出每只小鼠的 mask、持续 ID 和运动轨迹。多色鼠先作为容易场景跑通，同色鼠作为后面的重点攻关对象。

过渡：在这个拆分下，多色鼠和同色鼠虽然使用同一套总体框架，但身份关联所依赖的特征不同。

---

## 第 2 页：多色鼠——颜色可作为强身份锚点（约 60 秒）

对于多色鼠，因为不同个体的颜色和亮度差异比较明显，所以身份关联相对直接。

我的计划是，检测和分割部分先沿用现有检测器与 SAM 2.1，不急着更换整个框架。在得到每只鼠的 mask 以后，提取颜色和亮度特征，并把位置、速度和运动方向作为辅助信息。

关联时分成几层：首先用颜色进行门控，排除明显不可能的匹配；然后检查位置和运动方向是否连续；如果多个条件相互冲突，就不强行分配身份，而是把这一帧标记为 review，留给后续恢复或人工复核。

多色鼠阶段主要是建立基线。评测时不能只看画面上有没有框，还要先看检出率，再统计 IDSW，也就是身份交换次数，以及丢失帧和复核率。

过渡：多色鼠可以依靠颜色，但到了同色鼠场景，最明显的身份线索就失效了。

---

## 第 3 页：同色鼠——依靠外观记忆与时空历史（约 80 秒）

同色鼠是目前最需要优化的部分。两只鼠颜色接近时，单帧外观本身不够区分；特别是在接触、遮挡和交叉以后，系统很容易把两个 ID 交换。

我的思路不是只依赖一种新特征，而是把外观记忆和时空历史结合起来。

外观记忆包括局部纹理、体型、轮廓，后续也可以加入姿态关键点或者学习式的外观 embedding。它回答的是：这只鼠从外观上更像历史中的哪一个个体。

时空历史包括之前的位置、速度、运动方向和轨迹连续性。它回答的是：根据此前的运动趋势，这只鼠最可能从哪里来到当前的位置。

关联时把这两类信息融合成匹配分数。高置信度时保持或恢复 ID；低置信度时不硬判，先进入 review，等两只鼠分离以后再重新关联。

后续实验不能只选容易片段，而要专门建立“接触—遮挡—分离”测试片段，重点统计这些困难片段中的 ID switch。这部分会直接检验同色鼠方案有没有真正改进。

过渡：明确同色鼠方案以后，下一个问题就是现有 V1 和 MOTIP 到底应该怎么选。

---

## 第 4 页：技术选型——V1 为主线，MOTIP 为对照（约 80 秒）

目前的结论是：不直接把 MOTIP 当成可以整套套用的现成答案，先以师兄的 V1 为主线。

V1 的优势是已经贴近当前小鼠场景，能够输出 mask 和 ID，也便于逐层排查问题。后面可以按照 detector、association 和 recovery 三层分别定位：如果小鼠根本没有被检测出来，就先解决检测；如果检测一直存在但身份换了，就重点改关联；如果问题发生在遮挡以后，就改恢复机制。

多色鼠先使用颜色与时空规则；同色鼠再逐步加入更强的外观记忆或学习式特征。

MOTIP 的思路是直接预测 box 和身份 ID，但它依赖训练过的检测器以及 ID decoder，需要目标域数据和训练过程。因此它不等同于当前所说的“零新增训练标注”方案，而且默认输出是检测框，不是我们现有流程中的精细 mask。

所以现阶段把 MOTIP 作为 box 加 ID 的对照基线更合理。在同一批测试视频上先比较检测和身份指标；如果它的检测在小鼠场景中可靠，再研究它的 ID decoder 能不能用于增强同色鼠的身份关联模块。

最终采用的是一个可逐步替换的结构：检测和分割先沿用 V1，身份模块逐步增强，MOTIP作为统一数据上的对照，而不是一开始就推翻现有方案。

过渡：基于这个选择，下一阶段的学习和实施可以按四步推进。

---

## 第 5 页：学习与实施路线（约 60 秒）

下一阶段我计划分四步推进。

第一步是复现基线。把现有代码的输入、输出和参数读清楚，分别跑通短视频和长视频，并保存失败片段，而不是只看成功示例。

第二步是建立小规模评测集。评测集同时包含多色鼠和同色鼠，并覆盖接触、遮挡、交叉和重新分离等场景。为了能客观比较，需要做少量人工真值，但这些标注主要用于评测，不一定用于训练。

第三步是分层改进。先确认 detector 的检出是否稳定，再分别测试 appearance、association 和 recovery 的改动，避免多个模块同时变化以后无法判断改进来自哪里。

第四步是对照验证。把 V1 和 MOTIP 放在同一批数据上比较，主要看 IDF1、HOTA、IDSW，以及需要进入 review 的比例。

因此，这周的进度定位是完成文献和代码学习、明确任务与技术路线。下一次汇报希望能够交付三项内容：可复现的 V1 基线、小规模评测集，以及第一版多色鼠结果。实施顺序是先保证检测稳定，再解决身份关联；其中同色鼠是主要优化点，MOTIP暂时不直接套用。

## 收束（约 15 秒）

以上是这周完成的学习和任务拆解。下一阶段我会先用多色鼠把整个流程和评测跑通，再集中处理同色鼠在接触与遮挡后的身份恢复问题。

# 导师可能追问

## 1. 所以主要优化点是不是检测器？

不完全是。检测器是前提，需要先确认每只鼠能否持续被检出；但对于同色鼠，如果检测结果一直存在而 ID 仍然交换，主要问题就在身份关联和遮挡恢复。计划是先把检测稳定性量化，再决定优化重点，不能预先把所有问题都归到检测器。

## 2. 为什么不直接套用 MOTIP？

因为 MOTIP 不是无需训练的通用鼠类模型。它需要适配目标域的检测器和身份训练数据，默认输出也是 box，而现有 V1 已经能输出 mask。现阶段直接替换风险较大，更适合先作为对照基线；确认其检测可用以后，再考虑借鉴或接入 ID decoder。

## 3. “零训练标注”到底是什么意思？

这里更准确的说法是：在新视频或新实验上，尽量不额外制作大规模人工训练标注，直接利用预训练模型、首帧提示、外观与时空信息完成追踪。它不代表完全没有人工输入，也不代表不需要评测真值；首帧初始化、低置信复核和少量评测标注仍然可能需要人工参与。

## 4. 同色鼠具体依靠什么区分？

主要融合三类信息：一是局部纹理、体型和轮廓等外观信息；二是位置、速度、方向和轨迹连续性等时空信息；三是接触前建立的历史身份记忆。置信度不足时不强行分配，等分离后再关联。

## 5. 下一次汇报能看到什么实际产出？

计划至少给出三个可检查的结果：现有 V1 能够稳定复现；建立一套包含多色、同色、接触和遮挡片段的小评测集；得到第一版多色鼠的检出率、IDSW、丢失帧和复核率结果。
