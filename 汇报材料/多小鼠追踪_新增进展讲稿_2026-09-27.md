# 同色小鼠 SAM 优化进展讲稿 · 2026-09-27

对应《多小鼠追踪.pptx》新增第 14–18 页。逐页讲述约 10 分钟，含三段视频约 45 秒；后面的问答仅供备答。原有第 1–13 页保留，属于此前进展，不必逐页重讲。

本周主线：扩大时间范围后发现身份错误会持续累积，因此优先研究 SAM 的记忆更新与遮挡后的身份恢复。坚持零新增人工训练标注、零人工提示；公开人工答案仅用于离线评价。本周没有新增 MOTIP ID Decoder 的实验结果。

## 第 14 页｜长视频中的身份一致性

这周我把实验从之前的短片段扩展到了两段完整录制：一段三只鼠，接近七分钟；另一段五只鼠，接近八分钟，总时间大约十五分钟。

这里首先要区分两个问题：一个是能不能把小鼠的轮廓分出来，另一个是分出来以后，这个 ID 是否一直属于同一只鼠。现在较低的是后者，不能把表里的百分比理解为像素分割准确率。

长视频使用的是基于 SAM 2.1 的 DAM4SAM 多目标实现。它在三鼠前一分钟的 39 次身份核验中，有 38 次正确；五鼠前一分钟是 65 次中 64 次正确。只看前一分钟，确实会觉得结果很好。

但是，把时间扩展到完整录制以后，三鼠的正确判定占全部判定约 45.5%，五鼠约 59.1%。这说明短片段表现好，并不能保证长时间身份不漂移。一旦跟错了，后面可能连续很久都在跟同一个错误对象，累积成大量错误判定，而不一定是每个时刻都发生一次新的换 ID。

这些结果用公开的人工身份框进行抽查，首次只用来对齐编号，之后固定对应关系，不再重新配号。两段一共 809 次“某个时刻、某个身份”的判定，不是 809 个独立视频。无法判定也保留在分母里，没有删掉。

还要强调实验限制：为了在本机运行，本次输入缩到 512，每六个原始帧处理一个，实际大约每秒十一帧。因此目前能说的是“这个本机配置存在长期身份问题”，还不能据此说原版 SAM 默认设置不行，也不能反驳师兄在其他配置下效果很好的观察。

## 第 15 页｜三鼠案例：接触后两个 ID 跟向同一只

【点击播放视频。左边原视频，中间 DAM4SAM，右边是 DAM4SAM 加入本项目跨 ID 冲突记忆冻结后的结果。约 15 秒。】

这段视频截取的是原视频约 100 到 115 秒，三栏是同一个原始帧索引的同步对照。

中间这一栏在大约 104.60 秒出现了两个掩膜的严重重叠。这里“严重重叠”是程序预先定义的可疑信号：任意两个不同预测 ID 的掩膜，交集面积达到较小掩膜面积的 50% 或以上；不是说这一帧已经由人工确认身份错误。到 107.46 秒的人工答案抽查时，才可以确认：本来应该对应不同小鼠的两个预测槽位，跟到了同一只鼠身上。

画面里有时只明显看见一个编号，是因为后画的掩膜和文字盖住了前一个。程序输出实际上仍有两个槽位，只是它们指向了同一个对象。所以不能仅凭画面上好像有几个颜色，来判断身份是否正确。

右边做了一个很小的改动：当不同槽位严重重叠时，撤销这些槽位本帧的记忆和对象指针更新。DAM4SAM 原本就会跳过空掩膜，并对近期、历史记忆做筛选；这里的“跨 ID 重叠达到 50% 后冻结”是我们额外加的实验规则，不是 DAM4SAM 原论文自带的规则。当前帧的预测仍保留，不是直接把可疑结果从画面或评分中删掉。

同一时刻，右边的三个身份在人工抽查中均对应正确。这个现象支持我们继续研究“错误记忆是否会放大身份漂移”，但还只是已看过的开发片段上的初步证据，不能说遮挡后的同色鼠身份问题已经解决。

【师兄追问具体错误时】三鼠初始槽位 1、2、3 分别固定对应人工身份 3、1、2。107.46 秒时，基线的槽位 1 应该属于人工身份 3，却落入身份 1 的框；槽位 2 也在身份 1 的框里。视频编号是预测槽位，不是逐帧用人工答案修正后的编号。

## 第 16 页｜五鼠案例：局部改善仍会在后段失效

【先点击左侧视频，10 秒；再点击右侧视频，20 秒。】

这一页用同一段五鼠视频说明，为什么既要找优化方法，也要把测试时间拉长。

左边的短片是 50 到 60 秒。这个视频内部，左栏是官方 SAM 2.1，右栏是 DAM4SAM。到 59.09 秒的人工抽查，官方版本有一个身份跟错，而 DAM4SAM 对应身份正确。说明记忆选择确实可能帮助解决某些局部干扰。

但是，右边截取同一录制的 125 到 145 秒。这个视频内部，左栏是原片，右栏是 DAM4SAM。到 131.82 秒，DAM4SAM 的槽位 3 和槽位 4 又跟到了同一只鼠身上。

因此我不会把前一个片段的成功当成整套方法已经稳定。我们目前观察到的关键失败，是对象接触或遮挡之后，两个追踪槽位合并到同一个对象，而且错误可能持续下去。这比单纯“有没有分出一个鼠形状”更值得研究。

这两段是为了说明机制而挑出的案例，不是用精选视频代替整体评价。整体计数仍然是上一页的完整时间范围结果。

## 第 17 页｜SAM 优化方向与论文依据

围绕这个现象，我整理了四条最直接的文献方向。

第一条是已经在本机测试的 DAM4SAM。它不是简单保留最近几帧，而是结合近期外观和更有区分度的历史记忆；原方法已有空掩膜不更新及近期／历史记忆筛选。我们已经看到它能改善一次局部错误，但单独使用仍不足以保证长视频身份稳定。我们测试的跨 ID 严重重叠冻结，是在其多目标实现上追加的规则，不能归为 DAM4SAM 原方法。

第二条是 SAMURAI。它引入运动预测，辅助判断哪个候选掩膜更符合目标运动，并筛选进入记忆的内容。这个方向不需要重新训练 SAM，但原始实现主要面向单目标，迁移到多只同色鼠时还需要考虑对象之间不能重复占用同一身份。

第三条是 SAMIDARE。它更直接处理拥挤多目标场景：控制不可靠记忆写入，在目标比较分离的时候重新生成掩膜，再结合对象状态关联。它和我们现在发现的问题很接近。不过原项目面向体育场景，不能直接拿它的行人候选来源来检测小鼠，需要替换为自动的小鼠候选生成方法。

第四条是 SAM2Long。它不在每一步只保留一个分割结果，而是保留多条可能路径，利用累计证据作选择。对于遮挡后暂时分不清身份的情况，这个思路很有启发。但计算成本更高，而且最终路径选择会利用整段信息，必须与只使用当前及过去帧的在线方法分开评价。

所以接下来不是盲目加一个更复杂的模型，而是先验证两个明确问题：第一，冲突时控制记忆写入能改善多少；第二，对象重新分开以后，自动重提示和一对一关联能不能进一步恢复身份。

冻结记忆、运动约束、匈牙利匹配、重新提示都已有相关工作。目前我们的定位是基于文献做适配和验证，不能把这些组件的组合直接称为原创算法。

## 第 18 页｜初步消融结果与下一步验证

目前已经完成同一段三鼠前 180 秒的对照，保持权重、自动初始化、输入大小和抽帧方式一致。先看最小改动的两组：基线和仅冲突记忆冻结，它们只改变发生冲突时是否允许相关对象更新记忆。

基线有 85 次正确、33 次错误、2 次无法判定。加入冲突记忆冻结后，是 118 次正确、0 次错误、2 次无法判定。正确占全部判定的比例从 70.8% 变成 98.3%。两组分母都是 120，没有通过删掉错误结果来提高比例。

掩膜本身的严重重叠，也从 2,010 个处理帧中的 842 帧，降到了 13 帧。统计口径是：在一个处理帧里，只要任意两个不同预测 ID 的非空掩膜，其交集面积除以较小掩膜面积达到 50% 或以上，就把该处理帧计为一次“严重重叠帧”；同一帧有多对冲突也只计一帧，空掩膜不计入这个指标。冻结不会消除触发它的当帧重叠；我们的机制假设是阻止可疑掩膜写入记忆，使后续帧不容易持续把两个 ID 跟到同一只鼠上，从而降低累计重叠帧数。这个对照支持该方向，但还不足以证明每一次减少的因果来源。这里是预测自身的一致性检查，不是人工身份答案；冻结后仍然存在重叠帧，所以“抽查中没有发现错误”不等于“逐帧百分之百正确”。

第三组是冻结后尝试自动重提示，并要求连续三个处理帧支持恢复。它只有 83 次正确、31 次错误、6 次无法判定，没有超过基线，明显不如仅冻结。因此更复杂的分支目前不能算有效改进。它还改变了受影响对象的记忆隔离时长，下一步需要把这些因素拆开，不能把负结果简单归因于重提示本身。

具体实现是：传播前暂存各对象的记忆状态；传播后，如果两个不同预测 ID 的非空掩膜交集达到较小掩膜面积的 50% 或以上，就撤销相关槽位本帧的记忆和对象指针更新。普通帧仍然正常更新。代码还会将空掩膜视为需要阻止相关对象记忆更新的冲突，但不把它计入上面的“严重重叠帧”。这个版本没有重新训练，也没有读取人工答案进行推理。

和上周的工作相比，上周主要是在输出端拒绝不可靠身份、尝试用外观模板接回；这周这个改动进入了 SAM 追踪过程内部，控制错误信息是否继续进入记忆。两者不是同一个功能。

但这段三鼠视频已经用于观察失败和设计规则，所以这里只能称为开发集上的初步消融结果。下一步先固定冻结规则，去新增录制上验证；重提示分支再拆分隔离策略、联合关联和确认机制，找出失败原因。同时补做更高输入分辨率和更高处理帧率，排查本机降配是否放大了问题。

数据方面，目前共准备了六段、约 44 分钟，新增了七鼠、十鼠、白鼠以及另一组五只黑鼠。但这些是已下载的待测数据，不能说已经全部跑完。白鼠场景还需要适配自动初始化。

我希望和师兄确认的重点是：能否优先围绕“冲突感知的记忆更新和自动恢复”继续做实验，以及能否拿到他效果较好的运行配置作为对照。等新增视频上重复成功、消融完整后，再判断是否有足够明确的研究贡献。

## 可能被问到的问题

### 所以现在准确率到底低不低？

目前这个本机长视频配置的身份一致性确实偏低：三鼠 45.5%，五鼠 59.1%。但它不是像素分割准确率，也不是原版 SAM 默认配置的公认性能。冲突记忆冻结在一个三分钟开发片段上有明显改善，尚未证明对更多视频泛化。

### 既然有人工标注，为什么还有“无法判定”？

人工数据是稀疏的身份框，不是每帧精确掩膜。本次用预测掩膜质心落在哪个人工框里来核验身份；有时质心同时落进两个重叠的人工框，无法唯一判定。完整两段中有 42 次这种情况，另有 1 次落在所有框外。它们没有被算作正确，也没有从分母中删掉。这与上周“算法主动拒识而输出未知”的含义不同。

### 809 次判定怎么算的？

三鼠有 93 个评分时刻，每个时刻 3 个身份，得到 279 次；五鼠有 106 个评分时刻，每个时刻 5 个身份，得到 530 次，总计 809 次。首次身份编号对齐的时刻排除。每 300 个原始视频帧对应一个人工抽查时刻：三鼠约每 4.48 秒一次、五鼠约每 4.55 秒一次。它们具有时间相关性，不能当作 809 个独立样本来计算泛化置信区间。

### 为什么还会出现掩膜重叠？

不同对象的传播结果不天然等同于全局的一对一身份分配。相似外观、接触或遮挡可能让两个对象状态都预测同一个前景。把重叠像素硬分给一方只能让画面不重叠，不能证明 ID 正确。本次先尝试阻止这些可疑结果继续写入记忆。

### “严重重叠帧”就是身份错误帧吗？DAM4SAM 自带冻结规则吗？

都不是。“严重重叠帧”只按预测掩膜判断：某个处理帧内，任意两个不同 ID 的非空掩膜交集占较小掩膜的至少 50%，该帧就计一次；它可能是错误预警，但不能替代人工身份核验，非重叠的 ID 互换也可能漏掉。DAM4SAM 自带空掩膜不更新和记忆筛选；跨 ID 重叠达到阈值后撤销相关对象本帧记忆更新，是我们的附加实验规则。

### 为什么冻结后“严重重叠帧”变少？

它不会把当前两张掩膜改成不重叠；当前输出照常保留。若本帧可疑重叠被写入记忆，下一帧可能继续把两个 ID 引向同一只鼠。冻结这一次更新后，后续传播仍可使用此前较可靠的记忆，因此持续重叠有机会减少。842 帧到 13 帧是这段开发视频上的观测，不等于已经证明所有场景都有效，也不能单凭这个指标证明身份正确。

### 新方法是不是 98.3% 准确率？

只能说：在这一个已用于开发的三鼠前 180 秒上，120 次稀疏身份核验中有 118 次正确、2 次无法判定。不能称为全数据准确率，不能说连续每帧都正确，也不能称为独立测试结果。

### 这是零训练标注吗？

是零新增人工训练标注，也没有人工点击初始化；使用的是已有通用预训练权重，不能说基础模型从未用过人工标注。已知鼠数作为元数据，自动生成初始提示。公开人工 GT 只用来评价。鼠专用 SAM2Mice 权重则使用过鼠领域人工标注训练，因此与严格通用零样本结果分开。

### SAM2Mice 是否更好？

当前五鼠前 60 秒探索中，鼠专用 Base+ 为 62 正确、0 错误、3 未判定；通用 Base+ 为 64 正确、0 错误、1 未判定，都是 65 次稀疏核验。这个小样本不足以排名，且专用权重训练数据与测试数据是否重合尚不明确，暂不作为主要结论。

### 自动重提示已经证明有效了吗？

没有。已完成的三帧确认分支得到 83 正确、31 错误、6 未判定，低于仅冻结的 118/0/2；正确占全部判定为 69.2%，也没有超过基线的 70.8%。这个分支同时改变了记忆隔离时长，不能把差异只归因于重提示。本次 118/0/2 的正向结果只属于“仅冲突记忆冻结”。单帧确认分支另行运行，不计入本次主结论。

### 可以写论文了吗？

现在还不能这样判断。已有工作覆盖了记忆筛选、暂停写入、重提示和多路径搜索。至少需要独立录制上的重复收益、与最近方法的公平比较、组件消融、失败分析及运行代价，才能判断是否存在足够的新贡献。
